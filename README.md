# Week 4 — Next.js Assignments

This repository contains the Week 4 assignments completed during my Web Development Internship at Coding Pixel.

The assignments focus on building practical Next.js applications and understanding important concepts such as routing, data fetching, error handling, API route handlers, environment variables, forms, validation, and client-side interactions.

## 📚 Assignments

### Assignment 1 — Next.js Fundamentals

Focuses on the fundamentals of Next.js, including:

- Next.js App Router
- Pages and layouts
- Navigation between pages
- Reusable components
- Loading and error states
- Client and server components
- Local state and browser storage

### Assignment 2 — Data Fetching & Dynamic UI

Focuses on working with external data and creating an interactive interface.

Key concepts include:

- Fetching data from APIs
- Displaying dynamic data
- TypeScript interfaces and types
- Search and filtering
- Dynamic pages
- Loading states
- Error handling
- Responsive UI

### Assignment 3 — Route Handlers, Environment Variables & Forms

Focuses on handling user input and application configuration.

Key concepts include:

- Next.js API route handlers
- Reading environment variables
- Keeping configuration separate from source code
- Creating and handling forms
- Input validation
- User-friendly success and error messages
- Client-server communication
