## Country Explorer — Next.js

A responsive Country Explorer built with Next.js App Router, TypeScript, and Tailwind CSS.

## Features

🌎 Browse countries using the Countries API
🔎 Search countries by name
🌍 Filter by region
📄 Dynamic country detail pages
🏳️ View flag, capital, population, region, and languages
🗺️ Navigate to border countries
⏳ Loading and error states
❌ Not-found handling for invalid country codes
📱 Responsive design
🧭 Shared navigation and footer
