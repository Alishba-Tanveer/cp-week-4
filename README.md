# Assignment 3 — Route Handlers + Forms

# Overview

This project is a Next.js application that demonstrates how to handle user input using a form, validate the submitted data, and communicate with a custom API endpoint using a Route Handler.

The assignment focuses on three main concepts:

- Creating a custom API endpoint using Next.js Route Handlers
- Reading configuration values from environment variables
- Validating form input and displaying clear feedback to the user

# Features

- Custom Next.js API Route Handler
- Environment variable configuration using `.env.local`
- Client-side form validation
- Server-side validation
- User-friendly error messages
- Success message after valid form submission
- Loading state while submitting the form
- Responsive and modern user interface
- Professional animated background with decorative bubbles
